# Port Cast 시뮬레이션 (가상 운전자 PoC)

> STS 작업자의 상태를 읽어, 더 안전하고 빠른 하역을 만드는 AI — 2026 FLY ASIA 해커톤 1팀
>
> 팀 프로젝트 중 제가 맡은 **시뮬레이션·효과 검증 파트**만 공개한 저장소입니다.

발표 장표의 기능 번호와 PoC 구현의 대응:

| 장표 기능 | PoC 구현 | 범위 밖 (확장안) |
| --- | --- | --- |
| 01 조작 보조 | 숙련자 모방 모델(MLP) → 조이스틱 당김 | 실제 숙련자 원격 조종 로그 |
| 02 환경 보정 | 선박 상하·좌우 움직임을 반영한 2.5초 앞 위험 예측 → 진동·저항 | 기상(바람) 데이터 연동 |
| 03 주의 변화 감지 | 최근 4초 조작 패턴 → 작업자 상태 점수 → 보조 강도 조절 | 얼굴·시선 |

라이브 조종 없이, 가상 운전자가 2D STS 크레인 시뮬레이터에서 선박 위 셀 가이드에 컨테이너를 내려놓는 과정을 반복해 보조 방식별 효과를 비교한다.

## 실행 순서

```bash
python experiment.py 60      # 모방 모델 학습 + 상태 추정기 보정 + A/B/C × 3명 × 60회 (약 7분)
python make_charts.py        # 비교 차트 4종 + out/summary.csv
python make_state_chart.py   # 작업자 상태 그래프
python make_video.py 10      # 나란히 비교 영상 (약 6분, ffmpeg 필요)
python experiment_busan.py   # 부산신항 실측 해상 자료(Open-Meteo)로 바다 조건 재현
OMP_NUM_THREADS=1 python verify_1000.py   # 피곤한 작업자 A·C 각 1000회 재검증 (약 16분)
```

패키지: `pip install numpy pandas scipy matplotlib scikit-learn` (영상은 ffmpeg, 차트 글꼴은 Pretendard)

## 구성

| 파일 | 내용 |
| --- | --- |
| `crane_sim.py` | 크레인 진자 물리, 출렁이는 선박, 바람, 셀 가이드, 가상 운전자, 위험 예측, 숙련도 추정, 보조 모드 |
| `experiment.py` | 숙련자 모방 모델(MLP) 학습, 숙련도 추정기(로지스틱 회귀) 보정, 비교 실험 |
| `make_charts.py` / `make_state_chart.py` / `make_video.py` | 차트·작업자 상태 그래프·비교 영상 |
| `experiment_busan.py` | 실측 해상 자료(`data/busan_sea_hourly.csv`)로 평상시·거친 날 비교 |
| `verify_1000.py` | 60회 결과 재검증 (1000회, 95% 신뢰구간) |

## 보조 모드

- **A 보조 없음**
- **B 현재 상태 전달**: 지금 위험하면 진동 (기존 연구 방식)
- **C Port Cast**: 2.5초 앞 위험 예측 → 진동, 숙련자 모방 모델 → 당김, 예측 위험 → 내리는 방향 저항. 조이스틱 입력으로 추정한 숙련도가 낮을수록 강하게, 0.72 이상이면 끈다.

## 결과 (조건별 60회)

| 운전자 | 지표 | A 보조 없음 | B 현재 상태 전달 | C Port Cast |
| --- | --- | --- | --- | --- |
| 초보 | 정상 착지 | 18% | 42% | **78%** |
| 초보 | 거친 착지 | 62% | 32% | **0%** |
| 초보 | 실효 시간* | 69초 | 58초 | **56초** |
| 숙련(피로) | 정상 착지 | 28% | 50% | **77%** |
| 숙련(피로) | 거친 착지 | 48% | 15% | **0%** |
| 숙련 | 정상 착지 | 70% | 73% | 72% (보조 대부분 꺼짐, 보조 없음과 같은 수준) |

\* 실효 시간 = 착지까지 시간 + 거친 착지 점검 30초 + 가이드 충돌당 재정렬 15초 (가정)

- 숙련자−초보 성공률 격차: A +52%p → B +32%p → C −7%p
- 솔직하게 볼 점: 초보는 실효 시간도 C가 가장 빠르다. 지친 숙련자는 C(67초)가 B(64초)보다 약간 느리다(신중한 하강). 안전(거친 착지 0%)은 모든 운전자에서 C가 앞선다.

## 1000회 재검증 (피곤한 작업자)

60회 결과가 우연인지 보려고 같은 모델로 seed 0~999를 돌렸다 (`out/verify_1000_summary.txt`). seed 0~59는 `results.csv`와 같은 값이 재현된다.

| 지표 | A 보조 없음 | C Port Cast | C의 95% 구간 |
| --- | --- | --- | --- |
| 위험 사건 (거친 착지 또는 가이드 충돌) | 69.9% | **18.7%** | 16.3~21.3% |
| 거친 착지 | 44.0% | **0.0%** (0/1000) | 0~0.4% |
| 정상 착지 | 30.1% | **80.6%** | 78.0~83.0% |

거친 착지 0건은 측정상의 우연이 아니라 설계 결과다. C는 예측 위험이 크면 내리는 방향에 저항을 걸어 하강 속도를 줄이므로, 1000회 중 가장 센 착지도 0.53 m/s로 기준(0.6 m/s)에 닿지 않았다. 그래서 효과의 크기는 0이 되지 않는 위험 사건 비율(약 70% 감소)로 보는 편이 정확하다.

## 한계

- 실제 STS 운전 데이터가 아니라 **가상 운전자 모델** 결과다. 구조가 작동하는 원리를 보여줄 뿐 현장 효과 수치가 아니다.
- 숙련자 모방 모델은 코드로 만든 '숙련 운전자 정책'을 학습했다. 현장에서는 실제 숙련자 원격 조종 기록으로 대체한다.
- 위험 예측은 시뮬레이터 주행 기록으로 학습한 그래디언트 부스팅 모델이다(검증 AUC 0.995). 물리 모델 예측(predict_risk)은 비교·검증용으로 남겨 두었다.
- 2D, 단일 컨테이너, 착지 구간만 다룬다.
